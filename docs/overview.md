# 项目总览

「大理此刻」是一个聚焦**大理全域、实时、在场**的文旅活动与现场纪实平台。它不做传统攻略，而是呈现“此刻正在发生”的活动、打卡点与现场图文。

## 业务模块

| 模块 | 说明 | 主要接口前缀 |
|---|---|---|
| 活动 | 大理全域文旅活动：列表、详情、搜索、投稿、预约 | `/api/activities`、`/api/user/:id/bookings` |
| 景点 | 景点库：列表与详情 | `/api/scenic-spots` |
| 打卡 | 官方打卡点、用户打卡、打卡照片 | `/api/checkin`、`/api/photos/checkin` |
| 我在现场 | 现场图文动态：列表、详情、发布、点赞 | `/api/live` |
| 社区 | 社区攻略/帖子 | `/api/community` |
| 本地生活 | 本地生活分类与条目 | `/api/locallife` |
| 搜索 | 活动搜索与搜索历史 | `/api/search` |
| 用户 | 微信登录、资料、收藏、点赞、打卡记录 | `/api/user` |
| 区县 | 行政区划数据 | `/api/districts` |
| 敏感词 | 内容安全词库校验与管理 | `/api/sensitive` |

## 用户角色

| 角色 | 使用端 | 权限 |
|---|---|---|
| 游客 | 小程序 | 浏览活动、景点、打卡点、现场动态、社区内容 |
| 登录用户 | 小程序 | 收藏、预约、打卡、点赞、发布动态与投稿 |
| 管理员 | 管理后台 | 全模块内容 CRUD、审核上下架、Excel 批量导入、用户管理、敏感词与系统配置 |

## 各端职责

| 端 | 目录 | 职责 |
|---|---|---|
| 服务端 | `services/server` | 统一数据出入口：Node.js 提供面向客户端的公开 API，Flask 提供管理后台 API |
| 微信小程序 | `apps/miniprogram` | 面向 C 端的完整功能客户端 |
| 管理后台 | `apps/admin-panel` | 面向运营的内容管理与数据看板 |

## 数据流概览

1. 客户端（小程序）通过 HTTPS 调用 `/api/*`，GET 请求附带 HMAC 签名
2. Node.js 校验签名与频率后访问 MySQL，返回统一分页结构
3. 运营在管理后台通过 `/api/admin/*` 维护内容，Flask 侧完成审核与统计
4. 图片统一上传后按 cover/gallery/thumb 三档压缩落盘，由 Nginx 直接提供静态访问
